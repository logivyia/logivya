# DPIA Template

Status: `LEGAL REVIEW REQUIRED`

Use before releasing high-risk processing, a new provider/region, large-scale monitoring, special-category processing, profiling, biometric/location features, new WhatsApp data uses or material changes to export/deletion.

## Assessment

- Project/owner/review date:
- Purpose and expected benefit:
- Data subjects/categories/volume/frequency:
- Controller/processor roles and instructions:
- Data flow, systems, providers and countries:
- Necessity and less intrusive alternatives:
- Proportionality and user expectations:
- Lawful basis and transparency:
- Rights, consent/withdrawal and objection handling:
- Threats, misuse cases and incident impact:
- Existing safeguards:
- Residual risk (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`):
- Consultation/counsel/DPO decision:
- Approval, conditions and next review:

The `PrivacyDpia` record stores structured flow, risks, safeguards and residual risk. `HIGH` or `CRITICAL` residual risk blocks release until the required legal/security approval is recorded.
