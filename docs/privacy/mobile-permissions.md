# Mobile Permission Inventory

Status: `LEGAL REVIEW REQUIRED`

| Android permission/group | Present | Runtime prompt | Purpose/minimization |
| --- | --- | --- | --- |
| `INTERNET` | Yes | No | Production API, requested downloads and network operations |
| `POST_NOTIFICATIONS` | Yes | Yes | User-controlled notification delivery; denial preserves core app use |
| `VIBRATE` | Generated by notification module | No | Notification feedback |
| Network state / Wi-Fi state | Generated | No | Connectivity diagnostics and retry behavior |
| Wake lock / boot completed | Generated by notification module | No | Notification delivery and token recovery |
| Biometric / fingerprint | Generated by secure storage | User action only | Device-protected credential access where supported |
| `DETECT_SCREEN_CAPTURE` | Yes on Android 14+ | No | Normal install-time permission required by `expo-screen-capture`; protects the security screen and supports the platform callback without reading photos |
| Launcher badge permissions | Generated by notification module | No | Unread notification badge compatibility |
| Contacts | No | N/A | WhatsApp contacts are synchronized server-side; device contacts are not requested |
| Camera | No | N/A | Pairing QR is displayed, not scanned by the app |
| Photo/storage | No broad permission | N/A | Privacy exports use app-scoped file APIs and the system share sheet |
| Location/microphone/call log/SMS | No | N/A | Not required |

Android backup and cleartext traffic are disabled. Broad storage/photo access,
Google advertising ID and both AdServices ID permissions remain absent.
`DETECT_SCREEN_CAPTURE` is retained from Android 14 onward because the installed
Expo module registers the platform callback during native startup. Removing this
normal install-time permission causes Android 14+ to terminate the application
before the login screen is rendered.

This inventory supersedes the 2026-07-17 source-only permission snapshot for
Android 14+ releases. New permissions require a just-in-time explanation,
denial path, store-disclosure update and release review.
