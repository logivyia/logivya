manifest merge verified that broad storage/photo access, screen-capture
detection, Google advertising ID and both AdServices ID permissions are absent.
Merged manifest SHA-256:
`5FCF11FA5737BC061757127C8F6244E1B82DFF8423CBE2B00DDD228C7E8F1C40`.

This evidence applies to the current source candidate. The AAB already
published as v129 predates the removal and must not be described as if it were
retroactively changed. New permissions require a just-in-time explanation,
denial path, store-disclosure update and release review.
