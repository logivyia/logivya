# Acceptable Use Framework

Status: `LEGAL REVIEW REQUIRED - DO NOT PUBLISH`

Customers must not use LOGIVYA for unlawful messaging, harassment, fraud, malware, deceptive impersonation, prohibited content, rights infringement, unauthorized scraping, security bypass, resale of access, or processing special-category/children's data without an approved supported basis. Customers are responsible for recipient selection, required notices/permissions, suppression/objection handling and message content.

Enforcement should be proportionate, documented and appealable where appropriate. Emergency security suspension must preserve evidence and avoid unnecessary data exposure. Final prohibited categories, notice/suspension process and governing law require counsel approval.
