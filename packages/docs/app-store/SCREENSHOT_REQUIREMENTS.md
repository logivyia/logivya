# App Store Screenshot Requirements

## Required iPhone Sizes

Prepare screenshots for:

- iPhone 6.7 inch
- iPhone 6.5 inch if required by App Store Connect
- iPhone 5.5 inch if required for compatibility

## iPad Screenshots

The current config has `supportsTablet: true`, so App Store Connect may request iPad screenshots. Prepare iPad screenshots or decide before submission whether tablet support should remain enabled.

## Recommended Screens

Capture with safe demo data:

1. Login
2. Dashboard
3. WhatsApp Accounts
4. Groups
5. Send Message
6. Message History
7. Support
8. Subscription

## Rules

- Do not show real customer data.
- Do not show real phone numbers or emails.
- Do not show real QR codes.
- Do not show tokens, secrets, or private support messages.
- Use Turkish screenshots for the first Turkey-focused listing.
- Prepare English screenshots if English localization is enabled in App Store Connect.
