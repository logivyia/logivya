# Release Notes 1.0.0

## Turkish

Logivya mobil uygulamasının ilk kapalı test sürümü hazırlandı.

Bu sürümde:

- Güvenli giriş ve kayıt akışı
- Parola sıfırlama akışı
- Dashboard ve abonelik durumu
- WhatsApp hesap yönetimi
- Grup ve kategori yönetimi
- Mesaj oluşturma ve mesaj geçmişi
- Destek merkezi
- Bildirim merkezi
- Profil ve ayarlar
- Güvenli çıkış akışı

## English

The first closed testing release of the Logivya mobile app is ready.

This release includes:

- Secure login and registration
- Password reset flow
- Dashboard and subscription status
- WhatsApp account management
- Group and category management
- Message creation and message history
- Support center
- Notification center
- Profile and settings
- Secure logout flow
