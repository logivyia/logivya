# Google Play Screenshot Requirements

## Required Screenshot Sets

Prepare screenshots for:

- Phone portrait
- Optional: 7-inch tablet
- Optional: 10-inch tablet

## Prepared v178 Feature Screenshot Set

The Turkish phone set is ready under `packages/docs/google-play/store-assets-v178/`:

1. Dashboard — accounts, groups, and contacts at a glance
2. Categories — organize and filter WhatsApp groups
3. Messaging — plan the target workflow
4. Compose — send now, schedule, or repeat
5. Support — in-app support and ticket tracking
6. Subscription — plan and usage visibility
7. Notification personalization — channels, digests, and quiet hours
8. Security — two-step verification, app lock, and session control

Every prepared asset is 1080 x 1920 PNG and uses only safe demo data. Exact feature headings are rendered separately from the real app captures to preserve text accuracy.

## Requirements

- Do not show real customer names, real phone numbers, real emails, message contents, access tokens, QR codes, or private support messages.
- Use demo account data only.
- Use Turkish screenshots for the first Turkey-focused listing.
- Prepare English screenshots if an English listing is enabled.
- Ensure all screenshots match the app version submitted to Google Play.
- Do not publish the generated Turkish set under `en-US`; use `tr-TR`.

## Suggested Dimensions

- Phone: 1080 x 1920 or 1440 x 2560 PNG/JPG.
- Keep status bar clean.
- Avoid debug overlays.
