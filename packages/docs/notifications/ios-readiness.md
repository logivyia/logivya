# iOS Readiness

The data model and provider abstraction include `IOS_PUSH`, and the Expo receipt pipeline can distinguish Android and iOS devices. No iOS application release is claimed in this phase.

Before iOS launch, configure APNs/EAS credentials, add an iOS permission education flow, validate categories and deep links, test token rotation and user switching, and run App Store privacy review. The provider dashboard deliberately reports iOS as `FUTURE` until those gates pass.
